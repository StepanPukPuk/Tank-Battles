# Танковый бой — сборка Android-игры

В архиве готовый проект на Capacitor: игра лежит в `www/index.html`, остальное нужно, чтобы превратить её в приложение (APK).

## Что изменено для телефона
- **Управление пальцами** (альбомный экран):
  - левая половина экрана — джойстик движения: вверх/вниз — вперёд/назад, влево/вправо — поворот корпуса;
  - правая половина — прицел и огонь: пока палец на экране, танк стреляет, направление задаётся смещением пальца от точки касания.
- Меню, выбор модулей и настройки работают обычными нажатиями.
- **Музыка стартует сразу** при запуске приложения (в Android WebView автозапуск звука разрешается кодом в `tweak-android.js`). Музыка ставится на паузу, когда вы сворачиваете игру.
- Полный экран, альбомная ориентация, экран не гаснет, кнопка «Выйти» закрывает приложение.
- Три языка (RU / UA / EN) и бой на фоне меню сохранены.

## Что понадобится (один раз)
1. **Node.js 18 или новее** — https://nodejs.org
2. **Android Studio** — https://developer.android.com/studio (внутри уже есть нужная Java и Android SDK; при первом запуске согласитесь скачать компоненты).

## Сборка
1. Распакуйте архив, откройте папку в терминале (Windows: в папке нажмите на адресную строку, введите `cmd`).
2. Выполните:
   ```
   npm install
   npm run setup
   npm run open
   ```
   - `npm install` — скачивает зависимости;
   - `npm run setup` — создаёт папку `android`, применяет настройки (альбомный режим, полный экран, автомузыка);
   - `npm run open` — открывает проект в Android Studio.
3. Подождите, пока Android Studio закончит «Gradle sync» (полоса внизу).

### Запуск на телефоне
1. На телефоне: Настройки → О телефоне → 7 раз нажать «Номер сборки» → затем Настройки → Для разработчиков → включить **Отладка по USB**.
2. Подключите телефон кабелем, разрешите отладку.
3. В Android Studio выберите свой телефон вверху и нажмите зелёный треугольник ▶ — игра установится и запустится.

### Получить файл APK
- Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Когда появится уведомление, нажмите **locate** — файл `app-debug.apk` можно скинуть на телефон и установить (разрешите «установку из неизвестных источников»).
- Или в терминале: `cd android` и `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`). Файл будет в `android/app/build/outputs/apk/debug/`.

## Публикация в Google Play
1. Измените `appId` в `capacitor.config.json` на свой уникальный (например, `com.ваше_имя.tankbattle`) **до** `npm run setup`.
2. В Android Studio: **Build → Generate Signed Bundle / APK → Android App Bundle**, создайте ключ (сохраните его и пароль!) и загрузите `.aab` в Google Play Console.

## Иконка и название
- Иконка: в Android Studio правый клик на `app` → **New → Image Asset**.
- Название: поле `appName` в `capacitor.config.json`.

## Обновление игры
Меняйте `www/index.html`, затем `npm run sync` и снова запускайте из Android Studio.

## Если что-то не так
- **Музыки нет при запуске:** убедитесь, что `npm run setup` прошёл без ошибок (в конце должна быть строка «Android-настройки применены»). Проверьте, что на телефоне не включён беззвучный режим и громкость мультимедиа не на нуле.
- **Ошибка про Java/JDK:** в Android Studio откройте Settings → Build Tools → Gradle и выберите «Gradle JDK = jbr-17» (встроенная).
- **Игра в портретной ориентации:** повторите `npm run setup` на чистой папке (удалите папку `android` и запустите заново).
- **Без Android Studio:** можно открыть `www/index.html` в Chrome на телефоне и выбрать «Добавить на главный экран» — но музыка там начнётся только после первого касания.

## Сборка APK на GitHub (без Android Studio)
1. Создайте на github.com новый репозиторий (можно приватный) и загрузите в него **содержимое** распакованной папки `tank-battle-android` (включая скрытую папку `.github`). Через сайт: «Add file → Upload files» — перетащите всё; если `.github` не перетаскивается, создайте файл вручную: «Add file → Create new file», имя `.github/workflows/build-apk.yml`, и вставьте туда содержимое из архива.
2. Откройте вкладку **Actions**. Сборка запускается сама после загрузки, либо нажмите **Build Android APK → Run workflow**.
3. Через 5–10 минут откройте завершённый запуск (зелёная галочка) и внизу в разделе **Artifacts** скачайте `tank-battle-apk` — внутри `app-debug.apk`. Скиньте его на телефон и установите.
4. Любое изменение `www/index.html` в репозитории запускает новую сборку.

Это debug-версия: для установки на свой телефон её достаточно. Для Google Play нужна подписанная сборка (раздел «Публикация» выше).
